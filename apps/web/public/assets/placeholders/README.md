# Placeholders

Remplace ces fichiers (en gardant les mêmes noms) quand tu auras les assets définitifs :

- `favicon.svg` — icône d'onglet.
- `campfire.png` (à venir) — scène principale du feu de camp.
- `hero-<class>-portrait.png` (à venir) — portraits des classes.
- `building-<type>.png` (à venir) — icônes de bâtiments.
- `item-<slot>-<rarity>.png` (à venir) — icônes d'items.
